Hydrogen 是一款基于 [Jekyll](https://jekyllrb.com) 的极简风格静态博客主题，致力于用轻量化的模块，为你带来简洁、快速的阅读体验。
厌倦了无止境的加载与繁杂的页面内容？试试 Hydrogen，感受"轻盈、干净"的博客之旅。
## 核心特性
- **极致轻量**：无重型框架依赖，页面加载快速流畅
- **PJAX 无刷新加载**：SPA 单页应用般的顺滑体验（可开关）
- **MathJax 数学公式**：技术博客开箱即用（可开关）
- **Emoji 表情**：写作时直接使用 `:smile:` 语法
- **文章置顶 / 友链 / 标签系统**
- **自定义主题色与首页背景**
- **SEO 友好 + RSS Feed**
- **内置 Valine 评论**（LeanCloud 驱动，可自定义）
## 快速开始
```bash
git clone https://github.com/link9596/jekyll-theme-Hydrogen.git
cd jekyll-theme-Hydrogen
bundle install
bundle exec jekyll serve
```
